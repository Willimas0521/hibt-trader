# Hibt 期权自动交易助手

Chrome 扩展，用于自动在 hibt.com 完成期权交易操作。

## 功能

- ✅ 自动点击「60分钟」时间单位
- ✅ 自动填写交易金额（默认 10 USDT）
- ✅ 自动点击「买涨」按钮
- ✅ 支持定时自动循环交易
- ✅ 可视化操作界面

## 安装步骤

### 1. 打开 Chrome 扩展管理页面

在地址栏输入：
```
chrome://extensions/
```

### 2. 开启开发者模式

点击右上角「开发者模式」开关，开启后会出现三个新按钮：
- 加载已解压的扩展程序
- 打包扩展程序
- 更新

### 3. 加载扩展

点击「**加载已解压的扩展程序**」按钮，选择本文件夹（`hibt-extension`）。

### 4. 安装成功

看到扩展图标（绿色 H 图标）出现在 Chrome 工具栏即表示安装成功。

## 使用方法

### 首次使用

1. 打开 https://hibt.com/zh-cn/options/BTC-USDT
2. **登录你的账号**
3. 点击 Chrome 工具栏的绿色 H 图标
4. 设置交易金额（默认 10 USDT）
5. 点击「立即执行一次」测试

### 自动交易

1. 设置金额和间隔时间（分钟）
2. 点击「开始自动交易」
3. 扩展会每隔设定时间自动执行一次交易
4. 点击「停止自动交易」可随时停止

## 控制台调试

安装扩展后，在 hibt.com 页面按 F12 打开控制台，可以使用以下命令：

```javascript
// 执行一次完整交易
hibtTrader.execute()

// 开始每 5 分钟自动交易
hibtTrader.startAuto(5)

// 停止自动交易
hibtTrader.stopAuto()

// 单独步骤
hibtTrader.selectTime60()   // 点击 60分钟
hibtTrader.setAmount(10)    // 填写金额
hibtTrader.clickBuyUp()     // 点击买涨
```

## 注意事项

1. **必须先登录** hibt.com 才能使用
2. 如果页面有 Cloudflare 验证，需先手动通过
3. 金额设置会保存在本地，下次打开自动恢复
4. 自动交易期间请保持页面打开

## 故障排除

### 扩展图标不显示
- 检查是否已开启开发者模式
- 尝试刷新扩展页面（chrome://extensions/）

### 点击无反应
- 确保当前页面是 hibt.com
- 检查控制台是否有错误信息
- 尝试刷新页面后重试

### 找不到元素
- 网站可能更新了界面，需要调整选择器
- 在控制台运行 `hibtTrader` 查看可用方法
