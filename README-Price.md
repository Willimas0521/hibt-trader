# Hibt 价格监控自动交易

使用币安/OKX 免费 API 获取实时价格，当价格达到设定阈值时自动执行交易。

## 功能特点

- ✅ **完全免费** - 使用币安公开 WebSocket，无需 API Key
- ✅ **实时监控** - BTC/USDT 价格实时更新
- ✅ **价格触发** - 支持高于/低于阈值触发
- ✅ **自动交易** - 触发后自动执行买涨操作
- ✅ **可视化界面** - 实时价格显示、阈值管理

## 系统架构

```
币安 WebSocket ──► price-server.js ──► WebSocket ──► 浏览器扩展 ──► hibt.com
        │
        └── 实时监控 BTC/USDT 价格
        └── 检测价格阈值
        └── 触发交易信号
```

## 安装步骤

### 1. 安装依赖

```bash
cd hibt-extension
npm install
```

### 2. 启动价格监控服务器

```bash
node price-server.js
```

启动后会显示：
```
📊 Hibt 价格监控服务器
═══════════════════════════════════════════════════

[WebSocket] 等待扩展连接: ws://localhost:3001
[HTTP] API 地址: http://localhost:3002

功能:
  • 实时监控 BTCUSDT 价格（币安）
  • 支持设置价格阈值触发交易
  • WebSocket 实时推送给浏览器扩展
```

### 3. 安装浏览器扩展

1. 打开 Chrome: `chrome://extensions/`
2. 开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `hibt-extension` 文件夹

### 4. 使用扩展

1. 打开 hibt.com 并登录
2. 点击 Chrome 工具栏的扩展图标
3. 等待连接状态变为「已连接」
4. 设置价格阈值，点击「添加价格监控」

## 使用说明

### 设置价格阈值

在扩展界面：

1. **目标价格** - 输入触发价格（如：75000）
2. **方向** - 选择「高于」或「低于」
3. **金额** - 交易金额（默认 10 USDT）
4. **周期** - 时间周期（默认 60 分钟）
5. 点击「添加价格监控」

### 示例场景

**场景 1：突破买入**
- 当前 BTC 价格：$74,000
- 设置：≥ $75,000 时买入
- 当价格涨到 $75,000 时自动执行买涨

**场景 2：回调买入**
- 当前 BTC 价格：$76,000
- 设置：≤ $75,000 时买入
- 当价格跌到 $75,000 时自动执行买涨

### 监控列表

- 显示所有设置的阈值
- 已触发的显示 ✅
- 可以重置或删除阈值

## API 接口

服务器启动后提供以下接口：

### WebSocket (ws://localhost:3001)

连接后实时接收：
```json
{"type":"price_update","data":{"price":75000.5,"change24h":2.5}}
```

### HTTP API

```bash
# 获取当前价格
curl http://localhost:3002/price

# 获取所有阈值
curl http://localhost:3002/alerts

# 获取状态
curl http://localhost:3002/
```

## 数据源

默认使用 **币安 (Binance)** 免费 WebSocket：
- 地址：`wss://stream.binance.com:9443/ws/btcusdt@ticker`
- 更新频率：实时
- 无需 API Key
- 完全免费

## 故障排除

### 扩展显示「未连接」
- 检查 `price-server.js` 是否已启动
- 检查是否有防火墙阻止端口 3001

### 价格不更新
- 检查网络连接
- 币安 WebSocket 在国内可能需要代理

### 交易未执行
- 确保 hibt.com 已登录
- 检查浏览器控制台错误
- 确认元素选择器是否需要更新

### 如何切换数据源到 OKX？

修改 `price-server.js`：
```javascript
// 注释币安，启用 OKX
// connectBinance();
connectOKX(); // 需要实现此函数
```
